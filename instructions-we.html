Установка в Wallpaper Engine

Для пиратской / автономной версии:

  1. Скачайте архив с файлами живых обоев (форматы `.mp4`, `.html` или `scene.pkg`) с нашего сайта.
  2. Откройте корневую папку установленной программы Wallpaper Engine.
  3. Перейдите по пути: projects/myprojects.
  4. Создайте там новую папку с любым названием и распакуйте туда все файлы из архива.
  5. Перезапустите Wallpaper Engine — новые обои отобразятся во вкладке «Установлено».
